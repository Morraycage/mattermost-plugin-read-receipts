# Changelog

## 0.3.0

- `/receipts` slash command: the status of your last messages in a conversation, as a reply only you see. It works in the mobile apps, which do not run plugin code.
- Runs on Mattermost 6.0 and later (was 10.0). Tested on 6.3, 7.8, 8.1, 9.11 and 11.11.

## 0.2.0

- Support and release notes links in the manifest.
- The configuration is logged when it loads.
- Documentation: screenshots, configuration, usage, troubleshooting.

## 0.1.0

- First release: sent, delivered and seen status on direct and group messages, optional channels, per-recipient detail, recipient notice.
